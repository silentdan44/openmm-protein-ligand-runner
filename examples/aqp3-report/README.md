# AQP3 example report

This is an example HTML report from a short AQP3 membrane smoke run. The HTML and its PNG files are kept together so the report opens locally without external assets.

- Platform: CPU
- Membrane: 100 POPC lipids; 4,830 water molecules
- Dynamics: 1,000 NVT + 1,000 NPT + 2,000 production steps at 2 fs
- Analysis: 11 production frames; Cα distances for A:50–A:180 and A:60–A:160
- MMPBSA: GB model, all 11 saved frames

The trajectory covers only 4 ps of production. Its MMPBSA estimate and plotted variation demonstrate report generation; they are not suitable for scientific interpretation.
